Wie funktioniert eine Webseite eigentlich?

Eine Webseite zu programmieren ist gar nicht so kompliziert, wie es aussieht! Stell dir vor, du baust ein Traumhaus. Dafür brauchst du genau drei verschiedene Dinge:

🏠
1. Baustein

HTML = Das Rohbau-Skelett

HTML zieht die Wände hoch, setzt Türen und Fenster ein und teilt die Räume ein. Es bestimmt, was auf der Seite steht: Überschriften, Texte, Bilder und Knöpfe.

💡 Merkhilfe: Ohne HTML gibt es gar kein Haus!
🎨
2. Baustein

CSS = Einrichtung & Farbe

CSS streicht die Wände bunt an, wählt die Schriftart aus, legt Teppiche aus und rückt die Möbel an den richtigen Platz. Es sorgt dafür, dass das Haus schön aussieht.

💡 Merkhilfe: Ohne CSS wäre das Haus grau und kahl!
⚡
3. Baustein

JavaScript = Die Funktion

JavaScript legt Stromkabel, installiert Lichtschalter, die elektrische Türklingel und den Aufzug. Es macht das Haus lebendig und interaktiv.

💡 Merkhilfe: Macht Dinge klickbar und dynamisch!

Wie fängt ein HTML-Code immer an?

Das Grundgerüst, das in fast jeder HTML-Datei an oberster Stelle steht.

<!-- 1. Sagt dem Browser: Das ist modernstes HTML5 -->
<!DOCTYPE html>

<!-- 2. Startpunkt der gesamten Webseite -->
<html lang="de">

  <!-- 3. Der Kopf (Kopfdaten, unsichtbar für Besucher) -->
  <head>
    <meta charset="UTF-8">
    <title>Meine erste Webseite</title>
  </head>

  <!-- 4. Der Körper (Alles was man auf der Seite SIEHT) -->
  <body>
    <h1>Hallo Welt!</h1>
    <p>Das ist mein erster Text.</p>
  </body>
</html>
1
<!DOCTYPE html>

Der Begrüßungs-Befehl für den Internet-Browser (Chrome, Safari, Edge), damit er weiß, wie er die Datei lesen muss.

2
<html> ... </html>

Der große Klammer-Behälter. Alles, was zur Webseite gehört, steht zwischen diesen beiden Tags.

3
<head> (Der Kopfbereich)

Enthält Angaben zum Titel im Browser-Tab oder Einstellungen für Umlaute (ä, ö, ü). Das sieht der Besucher nicht direkt auf der Seite.

4
<body> (Der Körperbereich)

Der wichtigste Teil! Hier kommen Überschriften, Texte, Knöpfe und Bilder rein.
